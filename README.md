# 🛳️ Titanic EDA – Data Analyst Internship 

## 📌 Objective

This project involves performing **Exploratory Data Analysis (EDA)** on the Titanic dataset to extract insights and patterns that explain passenger survival. The analysis was done using Python libraries such as **Pandas**, **Matplotlib**, and **Seaborn** in **Google Colab**.

## 📊 What I Did

- Loaded and explored the Titanic dataset
- Handled missing data and checked data types
- Performed **Univariate**, **Bivariate**, and **Multivariate** analyses
- Created visualizations:
  - Countplots
  - Histograms & Boxplots
  - Correlation heatmaps
  - Violin plots
- Summarized key insights and patterns affecting survival

---

## 🔍 Key Insights

- **Females**, especially in **1st and 2nd class**, had the highest survival rates.
- **Males in 3rd class** had the lowest survival rates.
- **Fare, Age, and Pclass** were strong indicators of survival.
- Visualizations like **pairplots** and **heatmaps** helped uncover important relationships.
